RNN, LSTM and GRU: networks with memory

Language, speech, music, sensor readings and bank transactions all arrive as sequences: order matters, and what happened earlier changes what later items mean. Recurrent networks read a sequence one step at a time while carrying a memory forward. This page explains the plain RNN, then the two gated fixes, LSTM and GRU, with the maths, step-by-step walkthroughs and a live lab. The numbers are computed in your browser from real, trained models.

The running example: “the movie was not very good”

A review reads not … good. Counting positive and negative words gets this wrong (“good” is positive!). A model must remember that “not” appeared, and keep remembering it through the filler word “very”, until it meets “good”. That is exactly the job of a recurrent network, and it is also the job that separates the plain RNN from the LSTM and GRU. We also use a Kannada example in section 1.

Part 1

Why a network needs memory

An ordinary neural network treats each input independently: it sees one picture or one list of numbers and answers. For a sequence, the meaning of the current item depends on earlier items. A recurrent network therefore keeps a hidden state, a short vector of numbers that summarises everything read so far, and updates it at every step.
Many to one

A whole sequence in, one answer out.
Sentiment of a review, “is this UPI transaction history fraudulent?”

One to many

One input, a sequence out.
Describe a photo in words; generate a melody from a mood.

Many to many

Real-world example: a Kannada sentence that must remember its subject

In Kannada the ending of the verb depends on the subject, and the verb comes last. To write the right ending, a model has to remember who the subject was from the first word. Pick a subject and read the sentence word by word.

Part 2

The plain RNN

At each step the RNN does the same small calculation: it mixes the new word with its previous memory and squashes the result, producing the new memory. The same weights are reused at every step. Unrolled over time it looks like a chain of identical boxes passing a message along.
A person reading a review aloud and keeping a running impression in their head. After each word, the impression is updated from the old impression plus the word just read. There is no notebook; only the current impression.

The same weights W are used in all four boxes (weight sharing through time).

One step. With input xt (a vector of D numbers) and previous hidden state ht−1 (H numbers):
ht = tanh( Wx xt + Wh ht−1 + b )    h0 = 0
Wx is H×D, Wh is H×H, b has H numbers: H(D + H + 1) learnable numbers, no matter how long the sequence. tanh squashes each value into (−1, 1), so the memory cannot blow up in one step. For a yes/no answer, a final read-out turns the last state into a probability:
p = σ( R · hT + r ),   σ(a) = 1/(1 + e−a),   loss L = −[ y ln p + (1 − y) ln(1 − p) ]

Step-by-step walkthrough with a real trained RNN

These are the actual weights of a 4-unit RNN trained on a toy review task: each word is described by two numbers, polarity (good = +1, bad = −1) and negation (not = 1); every other word is (0, 0). The label is positive if the polarity is positive and no “not” appeared, or if both flip. Trained on sentences of 4 to 8 words; it gets all 300 unseen test sentences right.

Learning: backpropagation through time (BPTT). Unrolling turns the RNN into a deep network whose layers share weights, so we backpropagate through the chain. The gradient reaching the memory at step t comes from the loss and from step t+1:
∂L/∂ht = ∂L/∂ht|direct + WhT [ (1 − ht+1²) ⊙ ∂L/∂ht+1 ]
The weights’ gradients are the sum over all time steps of each step’s contribution, e.g. ∂L/∂Wh = Σt [ (1 − ht²) ⊙ ∂L/∂ht ] · ht−1T. The page’s code does exactly this and has been checked against numerical gradients (agreement to better than 10−5 relative error for all three models).
The weaknessEach step back multiplies the gradient by WhT and by a tanh slope (1 − h²) ≤ 1. Over many steps the signal shrinks towards 0 (vanishing gradient) or, with large weights, blows up (exploding gradient). Then the early words cannot influence learning. Section 6 shows this with real numbers.

Part 3

LSTM: a memory cell with gates

An LSTM (long short-term memory) keeps a separate cell state c, like a conveyor belt running straight through time. Three gates, each a number between 0 and 1 per memory slot, decide what happens to it: the forget gate erases old content, the input gate lets new content in, and the output gate decides how much of the memory to reveal as the hidden state h.
A notebook with a clerk. At each word the clerk asks: “Should I rub out something old?” (forget), “Should I write this new fact?” (input), and “Which notes should I read out now?” (output). “not” can be written once and left alone through “very” until “good” arrives, because the forget gate stays near 1 for that slot.

Schematic. Left to right on the belt: the forget gate scales the old memory, then the gated new content (input gate × candidate) is added; the result passes through tanh and the output gate to give the hidden state.

One LSTM step. Let vt = [ xt ; ht−1 ] (the two vectors joined). σ is the logistic function (0 to 1), ⊙ is element-wise multiplication.
ft = σ( Wf vt + bf )   (forget gate)
it = σ( Wi vt + bi )   (input gate)
gt = tanh( Wg vt + bg )   (candidate content)
ot = σ( Wo vt + bo )   (output gate)
ct = ft ⊙ ct−1 + it ⊙ gt
ht = ot ⊙ tanh( ct )
Four weight matrices instead of one: 4H(D + H + 1) numbers, four times the RNN. Why it helps: along the cell path, ∂ct/∂ct−1 = ft. If the network learns ft ≈ 1 for a slot, the gradient passes back unchanged instead of being multiplied by a weight matrix at every step. In practice the forget-gate bias is initialised to 1 so memories start out kept; this page does that.

Step-by-step walkthrough with a real trained LSTM

Same task, same sentences, 4 memory slots. Watch the cell row ct: when “not” arrives, is anything written, and does it survive “very”?

BPTT for the LSTM follows the same pattern with two gradient streams (∂L/∂h and ∂L/∂c). Key lines, with δht and δct the gradients arriving at step t:
δct = δct+1 ⊙ ft+1 + δht ⊙ ot ⊙ (1 − tanh²(ct))
gate gradients: ∂L/∂ft = δct ⊙ ct−1,   ∂L/∂it = δct ⊙ gt,   ∂L/∂gt = δct ⊙ it
The term δct+1 ⊙ ft+1 is the cheap highway for gradients.

Part 4

GRU: gating with fewer parts

The GRU (gated recurrent unit) keeps the idea of gates but drops the separate cell state: there is a single hidden state h. An update gate z decides how much of the old state to keep versus replace, and a reset gate r decides how much of the old state to use when proposing the new content.
A shop-floor whiteboard that one person keeps updating. For each item, a rule says “keep what is written” or “replace it with the new note” (update gate), and when drafting the new note, “how much of the old board should I look at?” (reset gate). No separate notebook, so fewer parts and quicker to train.

Schematic, simplified: the update gate blends the old state (weight 1 − z) with the candidate (weight z); the reset gate scales the old state before it is used inside the candidate.

One GRU step (with vt = [ xt ; ht−1 ]):
zt = σ( Wz vt + bz )   (update gate)
rt = σ( Wr vt + br )   (reset gate)
h̃t = tanh( Wx xt + Uh ( rt ⊙ ht−1 ) + bh )   (candidate)
ht = ( 1 − zt ) ⊙ ht−1 + zt ⊙ h̃t
Parameters: 3H(D + H + 1), three quarters of an LSTM. The last line is a leaky average: with z ≈ 0 the old state is copied unchanged, so ∂ht/∂ht−1 ≈ 1 along that path, the same highway idea as the LSTM’s forget gate. (Some libraries swap the roles of z and 1 − z; the models are equivalent.)

Which should I use?LSTM and GRU usually perform similarly; GRU is smaller and faster, LSTM is the safer default when sequences are long and data is plentiful. Try both on your problem. Plain RNNs are mainly for understanding, or for very short sequences. Many other practical choices matter more: bidirectional reading (a second network reads backwards), stacked layers, dropout and gradient clipping.

Part 6

Why plain RNNs forget: vanishing and exploding gradients

To learn that the word at step 1 matters, the error at the end must travel back through every step in between. Each step multiplies the signal by a number. If those numbers are below 1 the signal fades to nothing (vanishing); if above 1 it grows without bound (exploding). An LSTM or GRU gives the signal a path whose multiplier can sit near 1.
∂hT/∂hT−k = Πj=T−k+1..T diag(1 − hj²) · Wh    (RNN)
The size of a product of k matrices grows or shrinks roughly like (largest singular value)k. Shrinking tanh slopes (≤ 1) push towards vanishing. For the LSTM cell path, ∂ct/∂ct−1 = ft, so the product over k steps is just fk when the gate is steady.

Try it: gradient strength against distance

Read the chartVertical axis: log₁₀ of how much of a change at an early step still reaches the end (0 = fully preserved, −3 = one thousandth). With the scale below about 1 the RNN line plunges; near 1 it is fragile; well above 1 it explodes. Practitioners use gradient clipping (cap the gradient’s length) against explosions, and gated cells against vanishing.

Practical tricks you will meet

Embeddings

Words are turned into vectors xt (learned or pre-trained) before entering the network. In our toy we used two hand-made numbers per word.

Padding and masking

A batch needs equal-length sequences, so short ones are padded and the padded steps are ignored.

Truncated BPTT

For very long sequences, backpropagate only through the last k steps at a time to save memory.

Teacher forcing

When training a model that writes text, feed it the correct previous word instead of its own guess (the same idea used in Transformers).

Gradient clipping

Rescale the gradient if its length exceeds a threshold (1 in our lab) to stop explosions.

Why Transformers took over

Recurrence is sequential: step t must wait for step t−1. Attention compares all positions at once, which trains faster on large hardware and links distant words directly. Recurrent models remain useful for streaming data and small devices.
